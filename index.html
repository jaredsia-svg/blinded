Blinded

Efficient redaction for your most sensitive documents, all done locally.

Q&A

Redacting has never been easier.

Name a word or select a logo once, and every occurrence goes across your whole document – in the text and in images alike, including the ones no search box can reach.

Drop a document here

PDF, PNG, JPEG or plain text — or browse

  • Nothing is uploaded

    No server, no account, no analytics. The document is opened, read and rewritten inside this tab. No LLM is used. Close it and nothing remains.

  • Text, logos and pictures

    Type any word and every occurrence is redacted, even if the word is an image and not in text format. Pick out a logo, signature, or image and every other copy is redacted, regardless of size or colour.

  • Placeholders, not blanks

    Optionally label each redaction [P1], [E2], so a later reader — or a model — can still follow the sentence. The same thing always gets the same label.

  • Gone, not covered

    Each page is rebuilt from pixels, so there is nothing underneath the bars. No text, no fonts, no annotations — and none of the original author, title or history either.
