Key features

  • Nothing is uploaded

    No server, no account, no analytics. The document is opened, read and rewritten inside this tab. No LLM is used. Close it and nothing remains.

  • Text, logos and pictures

    Type any word and every occurrence is redacted, even if the word is an image and not in text format. Pick out a logo, signature, or image and every other copy is redacted, regardless of size or colour.

  • Placeholders, not blanks

    Optionally label each redaction [P1], [E2], so a later reader – or a model – can still follow the sentence. The same thing always gets the same label.

  • A full set of PDF tools

    Merge files, pull pages out, turn them, add text, draw on the page. Save a draft and pick the work up later. Works on a phone as well as a desktop.

Top use cases

  • Before it goes to an AI. Take the names and logos out, then paste the file into any model. The numbers and the argument survive; the party does not.

  • Deal materials. CIMs, board decks, diligence packs. Cover the target once and every copy goes, down to the badge in a chart on page 63.

  • Legal agreements. Counterparties, prices and signatures out. The clauses stay readable, so the precedent can be shared without the deal.

  • Discovery and FOIA. Covered text is gone from the file, not hidden under a rectangle somebody can select through. Each bar says what it removed.

  • Medical records. Names, dates, record numbers and hospital marks off a chart before it is used for research, teaching or a second opinion.
